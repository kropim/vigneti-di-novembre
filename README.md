# Vigneti di novembre

GitHub-Pages-Webseite für 13 Rennradtouren. Die ursprünglichen Zwischenorte sind in `touren.json` gespeichert.

**Wichtig:** Es sind noch keine vorab berechneten oder auf Asphalt geprüften GPX-Tracks enthalten. Die Webseite versucht, über den öffentlichen Valhalla-Routingdienst einen Fahrradrouten-Track zu berechnen. Ein GPX-Download wird erst nach erfolgreicher Berechnung freigeschaltet. Der Dienst kann ausfallen oder die Nutzung einschränken. Die gewählte Einstellung bevorzugt Rennrad und bessere Oberflächen, kann 100 % Asphalt nicht garantieren.

Zum Veröffentlichen alle Dateien in das Root des GitHub-Repositories hochladen; GitHub Pages aus `main` und `/(root)` aktivieren.
